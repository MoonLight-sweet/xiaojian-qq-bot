# xiaojian-qq-bot - 小简 (Xiao Jian)

基于 Google Antigravity (Gemini) 与 OneBot 11 构建的高情商、去AI味、具备人设自主演化与长期记忆能力的 QQ 群聊智能体驻场机器人。

---

## 项目概览

小简（大家也常叫她 Gemini）是一个活跃在 QQ 群聊里的猫系少女智能体。她聪明、嘴快、带着轻微的小恶魔俏皮感（轻度雌小鬼属性），既能在水群闲聊时自然地接梗、调侃与甩表情包，也能在遇到技术或复杂逻辑求助时瞬间切换为干练清晰的专业助手。

本项目在 Rust 高性能并发管道的基础上，结合 Google Antigravity 原生常驻会话机制，彻底解决传统语言模型机器人回复错位、冰冷客服腔、丢失引用上下文以及表情图片无法解析等痛点。

---

## 核心特性

(1) 人设自主演化与自主补全 (Self-Concept)
传统机器人在被问及个人偏好时容易抛出“我只是一个AI”的破坏沉浸感回答。小简具备自主演化机制：当被问到未明确设定的生活细节、游戏习惯、食物口味或番剧喜好时，会顺承猫系性格自信确立具体设定，并通过记忆操作写入持久记忆库，在后续交互中永远保持自洽与成长。

(2) 群聊引用与上下文双向追溯
群聊中常见的引用回复不再成为盲区。当用户引用群内历史消息、机器人上线前的发言或跨会话记录时，系统自动通过 OneBot 数据接口向上追溯原始消息文本与发送人身份，将被引用的上下文（最高支持120字符精准摘要）同步注入语言模型，确保回复针锋相对、绝不错位。

(3) 全格式表情包与图片多模态感知
全面放行腾讯官方图片CDN网络，内置图像视觉解析通道。无论群友发送的是普通照片、截图、QQ经典黄豆表情（`face`），还是商城动画表情（`mface`），系统都会完成图像下载、画面描述提取、文本识别与情绪判断，让小简像真人一样“看懂”群友发的表情包和图片。

(4) 真实社交与娱乐扩展功能
小简不仅限于被动接话，还拥有丰富的互动能力：
- B站冲浪：支持浏览B站热门视频、查看评论区神评，并自动从评论区收编热门表情包进入个人库存；
- 形象打理：支持根据心情或主人指令更换QQ头像、QQ群名片、个性签名与群头像；
- 空间动态：支持将群内发生的趣事、吐槽以自己的语气发表到QQ空间说说。

(5) 智能攒批与去AI味对话准则
- 攒批控制：群消息先进入缓冲池（静默窗口 + 数量硬顶），结合意图判断判断话题是否告一段落，避免单句刷屏打扰群聊；
- 严格去AI味：短句优先，禁止使用“好的呢”、“希望能帮到您”等客服腔；颜文字作为点缀而不是标点；优先使用真实图片表情包表达情绪。

(6) 长期记忆与额度保护机制
- 分群独立记忆：系统定期将原始聊天记录归纳压缩为结构化事实记忆，过长时自动触发遗忘算法，保持记忆干练；
- 额度智能调节：根据调用额度余量动态调节响应档位，额度紧张时自动收缩为仅回应点名与主人指令，防止额度枯竭导致服务中断。

(7) Web 可视化管理控制台
提供基于网页的后台控制面板，可随时在线查看机器人运行状态、调整群聊开启状态、编辑人设卡提示词、管理表情包库存与运行参数，所有改动即时生效。

## 系统架构

```
QQ 群聊 (NapCat / OneBot 11)
       │
       ▼ (WebSocket 事件流)
[输入归一化与安全防线] ─── (过滤非法输入、屏蔽敏感ID、解析表情与图片URL)
       │
       ▼
[消息攒批与节奏调度器] ─── (静默窗口聚合、超时熔断、额度分档)
       │
       ▼
[常驻会话管理层] ──────── (每群独立会话、交接纸条机制、MCP 工具面)
       │
       ├─► 记忆检索与自主演化 (SQLite 本地持久化)
       ├─► 视觉分析与表情库 (图片下载、OCR识别、pHash去重)
       └─► 社交扩展面 (B站浏览、空间发布、资料修改)
       │
       ▼
[出站发送与新鲜度拦截] ─── (过期回复丢弃、防刷屏控制) ───► 发送回 QQ 群
```

## 目录结构说明

- `src/`：机器人核心源码（Rust 实现）。
  - `src/agent/`：语言模型提示词工程、人设卡（`persona_card.txt`）与常驻会话管理；
  - `src/app/`：入站分发、批次组装、引用拉取、节奏控制；
  - `src/mcp/`：模型工具调用面（记忆检索、表情操作、B站冲浪、空间发布）；
  - `src/media/`：图片下载网络策略与多模态预处理；
  - `src/onebot/`：OneBot 11 通信协议适配与消息段转译；
  - `src/store/`：基于 SQLite 的本地数据库存取层。
- `web/`：网页端管理控制台前端工程。
- `sync-github.ps1`：一键提交本地修改至 GitHub 并触发云服务器拉取热更新脚本。

## 快速上手与运行

### 1. 运行环境要求
- 操作系统：Linux（推荐 CentOS / Ubuntu / Debian）或 Windows；
- 基础组件：Rust 工具链（1.80+）、Google Antigravity CLI（`agy`）、Docker（用于运行 QQ 协议端）。

### 2. 协议端部署 (NapCat Docker)
通过 Docker 容器运行 NapCat 作为 QQ 登录与通信协议底座：

```bash
docker run -d \
  --name napcat \
  --restart always \
  --network host \
  -e ACCOUNT=你的机器人QQ号 \
  -e NAPCAT_QUICK_PASSWORD=你的登录密码 \
  mlikiowa/napcat-docker:latest
```

### 3. 编译与启动机器人
克隆本项目到本地或服务器：

```bash
git clone https://github.com/MoonLight-sweet/xiaojian-qq-bot.git
cd xiaojian-qq-bot

# 复制并修改配置文件
cp config.example.toml config.toml

# 编译高性能发布版本
cargo build --release --bin gemini-qq-bot

# 启动服务
./target/release/gemini-qq-bot
```

### 4. Web 管理后台访问
服务启动后，浏览器访问管理控制台：
- 地址：`http://127.0.0.1:18081/console/`
- 在后台可直接查看实时审计日志、开关各个群聊的聊天权限、在线修改人设提示词。

## 同步与维护流程

本项目已配置本地与云端双向同步机制：
- 本地进行功能调整、人设微调或代码优化；
- 执行 `./sync-github.ps1 "更新说明"` 脚本，系统将自动提交修改并推送到 GitHub；
- 脚本同时会通知云端服务器自动执行拉取、增量编译并重启守护进程，实现零停机更新。
