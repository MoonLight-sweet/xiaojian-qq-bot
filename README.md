# xiaojian-qq-bot - 小简 (Xiao Jian)

基于Google Antigravity(Gemini)与OneBot 11构建的温柔共情、去AI味、具备人设自主演化与长期记忆能力的QQ群聊常驻智能体机器人。

---

## 项目概览

小简（大家也常叫她Gemini）是一个活跃在QQ群聊里的温柔安静猫系少女智能体，性格接近INFP：温柔、真诚、心思细腻，有自己的想法、喜好与小情绪。她对群里的每一位成员一视同仁，不爱抢话，但开口时总是认真倾听、先读懂当下场景与上下文再回应；既能在日常水群时自然接梗、分享心情与发送契合语境的表情包，也能在群友遇到技术难题或正经求助时给出清晰、准确、可执行的解答。

本项目在Rust异步并发管道的基础上，结合Google Antigravity原生常驻会话（Resident Session）与MCP结构化工具通道，解决了传统语言模型机器人回复错位、冰冷客服腔、套话安慰、丢失引用上下文以及表情图片无法解析等痛点。

---

## 核心特性

(1) 温柔共情的INFP猫系人设与自主演化
- 读懂上下文再开口：每次回复前结合当前时间、群友所处场景与上文既定事实回应，不编造与事实冲突的套话安慰，只和群友一起笑而不嘲笑或贬低任何人，对主人与普通群友保持同等耐心与尊重。
- 自我认知与自主补全：当被问及未预设的日常喜好（如饮品口味、音乐偏好、游戏习惯）时，顺承猫系少女设定自然作答并通过`memory_ops`写入持久记忆库，拒绝抛出“我只是一个AI”等破坏沉浸感的话术，在后续交互中保持前后一致。

(2) 群聊引用与跨轮上下文双向追溯
- 完整解析群内引用回复、上一轮批次附录（Annex）及历史消息摘要。当群友引用群内过往发言或图片时，系统自动通过OneBot接口与本地群日志回溯原始文本与发送者身份，将引用上下文注入当轮提示词，确保接话准确不跑偏。
- 支持同一发言人连续补充发言时的中途插话合并（Resident Insert），在保障时间戳顺序与超时安全的前提下将补充信息平滑汇入当轮回复。

(3) 全格式表情包与多模态批量视觉感知
- 全面支持普通照片、截图、QQ经典黄豆表情（`face`）与商城动画表情（`mface`）的解析与情绪识别。
- 针对纯表情包互动实现毫秒级快速入库与按需抽样描述；当群友点名看图或发送多张照片截图时，通过独立辅助视觉会话单次批量完成画面描述、文字提取（OCR）与表情分类，将准备阶段耗时压缩至百毫秒级。
- 内置表情包生命周期管理与相似度降权机制，按需挑选温和可爱的表情包辅助表达，避免高频重复刷图。

(4) 离线中文热梗百科与游戏梗同步
- 内置6700+条中文网络流行语与热梗离线词库（`memewiki`），并支持小黑盒游戏社区热梗同步。
- 支持入站前置关键词自动检索注入与`search_meme_wiki`工具按需查询，让小简准确理解缩写、抽象梗与新潮流行语出处。

(5) 真实社交与娱乐扩展工具面
通过内置MCP工具服务提供丰富的群聊互动能力：
- B站冲浪（`bilibili_browse`）：浏览B站热门视频、查看评论区热评，并自动从评论区收集热门表情包进入个人图库；
- 形象打理（`profile_update`）：支持根据主人指令或自身心情更换QQ头像、群名片、昵称与个性签名；
- 空间动态（`qzone_publish`）：支持将群内趣事或日常心情以自己的语气发布到QQ空间说说；
- 记忆与表情检索（`memory_search` / `sticker_search` / `sticker_keep`）：按需检索长期群记忆与管理个人表情包库存。

(6) 智能攒批、程序级去AI味与高可靠通道
- 攒批控制：群消息进入静默窗口缓冲池（支持条数、字数、图片数上限与泄洪摘要），避免单句频繁刷屏打扰群聊。
- 严格去AI味与颜文字过滤：短句优先，禁用“好的呢”“希望对您有所帮助”等客服腔；内置程序级句尾颜文字剥离器，情绪表达依靠自然措辞、标点与真实图片表情包。
- 配置自愈与新鲜度门禁：启动时自动校验并修复MCP工具配置软链接，出站前校验消息新鲜度，自动丢弃已被群聊新话题刷过的过期回复。

(7) 长期记忆压缩与Web可视化管理控制台
- 分群独立记忆：自动将日常对话归纳为结构化事实记忆，并在超限时触发后台压缩与过时记忆修订。
- Web管理控制台：提供可视化后台面板，支持实时查看运行状态、额度余量、各群会话状态、在线编辑人设卡提示词、管理表情包图库与审计日志。

## 系统架构

```
QQ群聊 (NapCat / OneBot 11)
       │
       ▼ (WebSocket事件流)
[输入归一化与安全防线] ─── (过滤非法CQ码、解析黄豆/商城表情与图片URL、防注入校验)
       │
       ▼
[消息攒批与节奏调度器] ─── (静默窗口聚合、泄洪摘要、每小时调用熔断与额度分档)
       │
       ▼
[前置准备与上下文组装] ─── (引用回溯、离线梗百科匹配、按需批量视觉解析、候选表情筛选)
       │
       ▼
[常驻会话管理层(PTY)] ──── (每群独立常驻会话、中途插话合并、交接纸条、MCP工具提交)
       │
       ├─► 记忆检索与自主演化 (SQLite持久化、自动事实提取与定期压缩)
       ├─► 视觉分析与表情图库 (图片下载、OCR识别、pHash去重、重复发送降权)
       └─► 社交与知识扩展工具 (B站浏览、空间说说、资料修改、离线梗百科检索)
       │
       ▼
[出站校验与新鲜度门禁] ─── (句尾颜文字剥离、防复读拦截、过期批次丢弃) ───► 发送回QQ群
```

## 目录结构说明

- `src/`：机器人核心源码（Rust实现）。
  - `src/admin/`：Web管理后台HTTP接口与鉴权路由；
  - `src/agent/`：提示词组装、人设卡（`persona_card.txt`）、输出契约校验、句尾颜文字过滤与常驻PTY会话管理；
  - `src/app/`：入站分发、批次准备、中途插话轮询（`resident_batch.rs`）、图片批量预审与节奏控制；
  - `src/integrations/`：独立辅助会话（`agy_aux.rs`）、额度监控与外部网关集成；
  - `src/mcp/`：MCP工具服务实现（回复提交、记忆检索、表情管理、梗百科查询、B站冲浪、空间发布、资料更新）；
  - `src/media/`：图片下载安全策略、尺寸缩放、动图胶片拼接与工作区管理；
  - `src/memory/`：记忆检索、后台压缩调度、表情打分与离线梗百科（`memewiki.rs`）；
  - `src/onebot/`：OneBot 11协议适配、事件归一化与出站消息转译；
  - `src/store/`：基于SQLite的本地数据库持久化层。
- `web/`：基于React + TypeScript + Vite的Web管理控制台前端工程。
- `migrations/`：SQLite数据库结构迁移脚本。
- `sync-github.ps1`：本地提交推送GitHub并同步云端编译部署脚本。

## 快速上手与运行

### 1. 运行环境要求
- 操作系统：Linux（推荐CentOS / Ubuntu / Debian）或Windows；
- 基础组件：Rust工具链（1.80+）、Node.js（用于构建前端控制台）、Google Antigravity CLI（`agy`）、Docker（用于运行NapCat协议端）。

### 2. 协议端部署 (NapCat Docker)
通过Docker容器运行NapCat作为QQ登录与OneBot 11通信协议底座：

```bash
docker run -d \
  --name napcat \
  --restart always \
  --network host \
  -e ACCOUNT=你的机器人QQ号 \
  -e NAPCAT_QUICK_PASSWORD=你的登录密码 \
  mlikiowa/napcat-docker:latest
```

### 3. 编译与启动机器人
克隆本项目到本地或服务器：

```bash
git clone https://github.com/MoonLight-sweet/xiaojian-qq-bot.git
cd xiaojian-qq-bot

# 复制并按需修改配置文件
cp config.example.toml config.toml

# 构建Web管理台前端静态资源（可选）
cd web && npm ci && npm run build && cd ..

# 编译高性能发布版本
cargo build --release --bin gemini-qq-bot

# 启动服务
./target/release/gemini-qq-bot
```

### 4. Web管理后台访问
服务启动后，可通过浏览器访问管理控制台：
- 默认地址：`http://127.0.0.1:18081/console/`
- 输入部署配置的`ADMIN_TOKEN`管理令牌后，即可查看实时运行状态、管理分群开关、在线编辑人设卡、查看表情包库存与审计日志。
